## 🧠 Sobre mim

Engenheira de Produção que migrou do chão de fábrica (PCP, custos industriais, melhoria contínua) para a **engenharia de dados**. Hoje construo, no **Estaleiro Mauá**, o ecossistema de dados ponta a ponta: ingestão incremental de APIs no **Microsoft Fabric**, modelos semânticos e dashboards em **Power BI**, automações com **Power Platform** e aplicações web.

Meu diferencial é unir **contexto de negócio industrial** — cronogramas de reparo naval, job cards, apontamento de horas, EVM — com **engenharia de dados moderna** e **estatística aplicada**.

- 🔭 Construindo pipelines Medallion no Fabric e um DW operacional de estaleiro em PostgreSQL
- 🎯 Meta: certificação **Microsoft Fabric Analytics Engineer (DP-600)** em dez/2026
- 📚 Cursando MBA em Engenharia de Dados (Descomplica) e MBA em Tecnologia para Negócios (PUCRS)

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Gear.png" width="22" alt="gear" /> Engenharia de Dados
- Ingestão incremental de **APIs REST** com **Notebooks PySpark** em tabelas **Delta** (bronze), com refresh particionado
- Orquestração **Notebook → Dataflow Gen2 → Lakehouse → Semantic Model** (arquitetura Medallion)
- Resolução de problemas reais de produção: conflitos de schema em merges Delta e truncamento silencioso de APIs em dias de alto volume
- Sincronização **API → Supabase/PostgreSQL** com upsert, paginação e tratamento de erros em lote

- Integração de fontes heterogêneas com chaves compostas em cascata e fuzzy matching
- Modelagem DAX avançada, visuais HTML customizados e edição de modelos via **MCP** com IA

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Smilies/Robot.png" width="22" alt="robot" /> Estatística, ML & IA
