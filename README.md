## 🧠 Sobre mim

Sou **Analytics Engineer**: trabalho na ponte entre a engenharia de dados e o negócio. Pego o dado bruto das fontes operacionais, **modelo, transformo, testo e documento** até virar uma camada semântica confiável, com métricas que significam a mesma coisa para todo mundo.

Venho da **Engenharia de Produção** (PCP, custos industriais, melhoria contínua). Por isso sei que perguntas o negócio precisa responder antes de escrever a primeira query. No **Estaleiro Mauá**, sou responsável pelo ciclo completo: ingestão no **Microsoft Fabric**, modelagem dimensional, modelos semânticos em **Power BI** e métricas de projeto como EVM, SPI e Curva S.

> 💡 **Eu uso a programação como ferramenta para dados, não como fim.** SQL, Python ou PySpark só entram quando resolvem uma pergunta de negócio: o que importa é o dado confiável chegando a quem decide.

- 🔭 Construindo um DW operacional de estaleiro em PostgreSQL e um pipeline com **dbt** + Dagster
- 🎯 Meta: certificação **Microsoft Fabric Analytics Engineer Associate (DP-600)** em dez/2026
- 📚 Cursando MBA em Engenharia de Dados (Descomplica) e MBA em Tecnologia para Negócios (PUCRS)
